# 威胁模型与安全目标

攻击者可以控制普通智能体及其合法密钥, 拼接路径, 重放, 延迟请求或造成节点失联. T 错误认证或根密钥泄露, 获准域身份机构谎报本域属性, 私钥主动共享, 恶意 C 绕过网关和超阈值串谋超出本方案的保证范围.

| 依赖的前提 | 在此前提下检验的性质 |
| --- | --- |
| T 正确核实 A/B/C 及其签发资格, 各方安全预置同一 T 根, 域注册机构及 IA/IB/IC 核实本域身份, 签发时检查全部声明, 验证方检查当前业务类型及全部可见/披露声明的资格 | SG1 拒绝伪造身份及越界使用的身份声明, 不声称识别未披露摘要对应的属性名 |
| 签名不可伪造, 哈希抗碰撞, 私钥与挑战随机源受保护, C 验证请求绑定及完整委托路径的逐跳约束 | SG2 凭证持有者绑定本次请求. SG3 子权限不超过祖先 |
| C 管理可信 RPC, 验证者满足 QBFT 阈值, 合约正确约束写权限 | SG4 在包含有效撤销的块上, 下游不能凭旧路径继续执行 |
| 出块和验证端时钟有界, C 执行端不能绕过网关 | SG5 状态或环境过旧时停止新放行 |
| C 的事务主库和受控观测器可信, 锁后按当前环境副本重新求值 | SG6 从订单还原实际采用的区块, 证据链, 策略和环境版本 |

T 的身份权威与 QBFT 的账本一致性是独立前提. 共识不能发现 T 的错误认证, T 离线也不能替代状态新鲜度检查. 一域资格撤销使依赖它的路径失败, 其他域独立路径仍可用; T 根泄露后的应急恢复须通过新部署完成.

文献 A1 支撑身份信任边界, B2 支撑持有者与会话绑定的比较, B3 支撑撤销成本的评价维度, C1/C2 分别用于策略与受限委托的比较. 文献来源见[文献清单](../../paper/论文.md). 验证节点的控制权假设见[网络与治理](../implementation/技术栈.md#1-网络与治理), 各性质的验证方法见[实验索引](../experiments/AGENTS.md).
