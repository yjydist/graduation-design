# E4 微基准

## 1 研究问题与范围

分别测量材料生成, 验签, 披露, 路径校验, 策略和状态装配的代价, 定位跨域认证与委托验证的开销来源. 使用确定性协议工具控制输入, 端到端负载见 [E5](E5-开放到达负载.md).

## 2 对照与变量

用 C0/B0 区分一致状态来源, 用 B0/B1 对照跨请求静态验签复用. 分开记录冷, 热条件, 写明缓存起始状态和实际命中. 按 [性能共用配置](实验计划.md#性能实验的共同配置)控制主体数, 深度, 域数, 属性数和策略规则数. 材料相关消融使用 [A-FULL/A-REUSE 定义](实验计划.md#1-实验地图与同语义对照), 同时核对动态判定保持一致.

## 3 输入与准备

根据 [F06](验证用例.md#1-采购闭环)准备真实签名和有效访问的固定夹具. RP/BM 配对使用相同主体, 委托深度和业务条件, 分别计入各自所需的证据及 C 本地服务资格. 记录实际属性, 证据包认证数和状态检查点. 记录构建, 种子, 冷热条件与计时范围.

## 4 执行与采样

| 阶段 | 原始采样 |
| --- | --- |
| 材料生成, ES256 签名与验签, 披露处理 | 阶段耗时, 分配量, 材料数量, 静态验签或缓存命中 |
| 路径遍历与收缩, OPA | 阶段耗时, 分配量, 实际路径和策略输入规模 |
| 挑战和事务 | 阶段耗时, 分配量, 查询次数和字节, 业务决定 |
| 一致快照开启与依赖装配 | 阶段耗时, 分配量, 查询次数和字节, 实际状态来源 |

一次变动一个因素, 按相同的种子与夹具重复测量. 冷热条件分开采集. 记录样本所属阶段, 实际配置, 单位和运行 ID. 对 B1 同时用 [S22](验证用例.md#2-身份-请求与父子约束)检查材料复用下的动态校验边界.

## 5 判据与缺测

对比适用配置的对应阶段, 并核对相同业务条件下的判定. 缺失阶段, 计数器或单位时, 在汇总保留缺测原因. 按[共用统计约定](实验计划.md#共用复现约定)记录独立重复数. 性能收益以实测差值为依据.

## 6 结果表和图

按阶段列冷热耗时, 分配, 查询次数与字节, 同列配置, 材料规模, 实际缓存命中和样本量. 对照图可分别展示状态装配及静态签名计算, 以运行 ID 链接原始计时和查询记录.
