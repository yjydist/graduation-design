# 技术栈与部署选择

C 在同一份授权视图中核对主体密钥, 祖先授权和任务. Fabric 的提交校验码决定登记写集是否有效, C 从自己的可信 Peer 接收完整块并原子生成视图, 将一次访问所需的所有依赖固定到同一高度. [Fabric 区块交付](https://hyperledger-fabric.readthedocs.io/en/latest/peer_event_services.html).

## 1 网络与治理

| 决定 | 配置和职责 |
| --- | --- |
| 业务域 | 采购 A, 协作 B, 供应 C 各有一个 Peer 和独立业务 MSP. PA 属于 A, C 独立决定接受订单 |
| 身份权威 | 三域共同预置 T 根. T 认证域及 IA/IB/IC 的签发资格, 用 TMsp 客户端提交提案和读结果 |
| 排序 | procurement 通道有四个 SmartBFT 排序身份, 由 A/B/C 及实验运维分别控制. 区块签名策略要求其中三个 |
| 登记 | 日常登记使用任意两个业务组织的 Peer 背书. 三域共同批准链码定义和初始根, 关键应用通道配置由三域管理员共同治理 |
| 准入 | 节点和客户端各有 MSP 证书, 节点 TLS 材料分离. 链码以 MSPID 和客户端证书 DER 的 SHA-256 核对对象写权限 |
| 时间 | 各 Peer 开启 TimeWindowCheck, 最大提案偏差 w=2 秒. 实验假设校时误差 epsilon<=1 秒, 受理资格按 3 秒裕度检验 |
| 读取 | C 使用自行管理的可信 Peer, 保留可重放的完整区块. C 的 PostgreSQL 同事务保存版本和检查点 |
| 新鲜度 | 每在线实例用专用客户端发送探针. 默认间隔 1 秒, 原发送后 5 秒到期, 仅可采用本进程发出且已应用的有效探针 |

四节点 SmartBFT 在协议假设成立时容忍一个拜占庭排序节点. 同机 Compose 实验中, 所有容器和密钥仍由同一宿主及运维控制, 容器停机与恢复只验证节点级故障. 机构级容错需要独立管理和故障域. 提案时间窗口与探针期限分别约束管理受理和在线视图. 记录时钟偏差和原始时间样本. [SmartBFT 配置](https://hyperledger-fabric.readthedocs.io/en/latest/bft_configuration.html).

## 2 组件与密钥

| 组件 | 选择 | 用途 |
| --- | --- | --- |
| 账本和链码 | Fabric 3.1.5, SmartBFT, Go 链码 authregistry, Peer LevelDB | 登记结构字段, 摘要, 状态和版本, 原子替换 |
| 管理交易 | Go Fabric Gateway 和 Fabric protobuf | 持久化原签名提案与交易, 查可信 Peer 的提交校验码, 恢复原 txID |
| 读视图 | 可信 Peer 的 Deliver, PostgreSQL 和 pgx | 应用有效写集, 保留同块多次更新的历史, 装配固定高度依赖 |
| 域服务 | Go net/http 和域间 mTLS | T 与 A/B/C 独立服务和数据库, 按登录角色选择管理证书 |
| 应用身份 | did:web, VC, SD-JWT, ES256/P-256 | T 签域认证, IA/IB/IC 签本域 VC, 业务方签委托和请求挑战 |
| 业务编码 | JWS, SHA-256 和 JCS | 验证原始签名字节, 规范 JSON 计算业务摘要 |
| 策略与订单 | 内嵌 OPA/Rego 和 PostgreSQL | C 在锁后用当前环境求值, 事务消费挑战并记录报价或订单 |
| 部署与测量 | Docker Compose, mise, Go 测试和负载驱动 | 重建夹具, 记录请求, 管理交易, 探针及资源开销 |

三域在部署时固定 T 的根 DID, 应用公钥, 文档摘要和管理证书绑定. T 的 DID 文档预置在本地, 访问端用固定摘要验证. 根变更需要新部署. 域身份机构换钥须 T 重新认证. 节点签名, TLS, 管理客户端及 DID 应用密钥分别生成和保管. DID 主机限已登记域名及受信 CA, 文档摘要和公钥转换见[协议编码](协议编码与测试向量.md#14-did文档-公钥与凭证上下文编码).

## 3 部署冻结条件

记录创世块和公开 MSP, 四排序身份及控制方, 通道和链码策略, 已提交定义及 sequence, 各组织安装 package ID, 构建和清单摘要, 实例标识, 容器资源及历史保留范围. 一次接受需要原交易的 VALID 校验码和块内位置. 在新实例使用新部署标识, 重新绑定签名向量和夹具. 实验的时钟误差, 网络控制及读取期限另行作为假设和测量变量. [部署与链上登记](部署与链上登记.md).
