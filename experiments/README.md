## 运行与复算

`experiments/` 作为独立 Go 模块 (`grad/experiments`) 接入 4 模块工作区, 通过统一 Cobra CLI (`cmd/exp`) 提供基线, 正式运行与离线复算入口. 在仓库根目录执行以下任务. 相对实例, 原始记录及输出路径均以仓库根为基准.

```bash
mise run experiment:test
mise run experiment:baseline -- --help
mise run experiment:run -- --help
mise run experiment:analyze -- --help
```

也可进入 `experiments/` 目录直接调用 `exp` CLI:

```bash
cd experiments
go run ./cmd/exp baseline --help
go run ./cmd/exp run --help
go run ./cmd/exp analyze --help
```

每个编号目录的 `method.md` 定义方法, `result.md` 记录结果, `runs/<run-id>/` 保存原始记录, `analysis/<run-id>/` 保存离线复算输出. [实验制品约定](AGENTS.md#正式实验制品).

## 实验用 LLM 配置

编辑 `experiments/llm.env` 指定 `LLM_MODEL` (模型名), `LLM_PROVIDER` (`openai` 或 `anthropic` 接口协议) 和 `LLM_BASE_URL` (服务地址). 运行前在项目根目录加载配置. API 密钥通过当前环境的 `LLM_API_KEY` 提供.

```bash
source experiments/llm.env
```

真实 LLM 实验在每轮清单记录实际模型名, 接口协议和服务地址.
