## 目录约定

| 实验目录内的路径 | 内容 |
| --- | --- |
| `result.md` | 正式结果, 含实际配置, 样本量, 图表, 异常, 结论和适用范围 |
| `runs/<run-id>/` | 一轮实验的配置, 原始数据和汇总, 包含失败或中止样本 |
| `figures/` | 结果报告和论文引用的图 |

完整约定见[项目说明](../AGENTS.md#正式实验制品). 新实验目录采用 `e<编号>-<英文主题>` 格式, 正式结果发布后在上表链接相应的 `result.md`.
