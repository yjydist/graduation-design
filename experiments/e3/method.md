# E3 动态调整与恢复

## 1 研究问题与范围

同一笔未执行的采购订单在改派, 换钥, 域资格或风险变化后, 哪个主体能继续使用已有报价, 需要重新签发或交付哪些材料? 另核对响应丢失后, 智能体是否能在正确停止发送的前提下查明原订单结果. [授权与策略](../../docs/DESIGN.md#3-委托授权与策略), [订单核账](../../docs/IMPLEMENTATION.md#7-订单核账).

## 2 对照与变量

从同一 Q800 的等价初始状态独立开始各条轨迹. 逐条改变授权, 密钥, 域认证, 服务, 策略或环境. 配对保留恢复或正负结果, 保持其他有效条件. 涉及缓存的轨迹记录是否命中及该次动态核对结果.

## 3 输入与准备

按 [F01-F06](../验证用例.md#1-采购闭环)建立有效委托和属于 B1 的 Q800, 分别初始化待测任务, 路径, 钱包和适用的 RP/BM 根. A1/B1/B2 接入真实 LLM, 通过工具调用执行需要智能体参与的步骤. 记录实际模型, 配置和初始检查点. [共用复现约定](../实验计划.md#共用复现约定).

## 4 执行与采样

| 变化 | 应观测到的效果 | 配对恢复或负例 |
| --- | --- | --- |
| 暂停 G1 / 撤销 G1 | 采用变更块后拒绝 G2 | 暂停可恢复且 `exp` 不变. 撤销后须新的有效路径 |
| 替换 G2, 改派 B2 | 原子撤旧建新, 重签叶子. B2 引用 B1 的 Q800 被拒 | B2 用新路径重新询价. 同 ID 覆盖或中途回退不产生交付 |
| B1 换钥 / 叶子 VC 被撤销 | 缓存命中时仍拒绝旧材料 | 核验新凭证并重签所引用的 G2. 同主体同任务可继续使用未过期原报价 |
| T 撤销 B 域认证 / 暂停 B 域 | 采用变更块后依赖 B 的路径失效, A/C 独立路径仍有效 | 撤销认证须 T 以新 ID 续发. 暂停可在原认证有效时恢复, 单独撤销的凭证或授权保持撤销 |
| T 同钥续发 / IB 换钥后重新认证 | 旧认证失效, 更新认证材料后重新绑定请求 | 同钥同范围可复用原有效 VC/委托. 换钥须重签引用旧版本的 VC 和委托. 原报价截止不变 |
| T 同钥收缩声明范围 / 普通主体管理账户恢复 | 分别判断隐藏与披露非必需属性. 恢复后旧管理证书绑定和旧应用版本失效 | S93 用同一 VC/路径作披露配对. S95/S97 核对原 `status` 保持, 新凭证和新路径完整后才可访问 |
| 停 T 服务 / 收紧 C 的准入 | 认证有效且状态新鲜时能本地验证. 被禁的业务条件仍被拒 | 依据实际已登记的撤销和续发状态及原截止判定, 超龄或缺材料拒绝. 更高策略版本调整业务准入, 身份根保持固定 |
| 取消任务 / 风险升降 / 缩短绝对期限 | 取消不可逆. `ELEVATED` 仅许询价, `BLOCKED` 全拒. 到达截止秒拒绝 | 用真实新环境观测恢复 `NORMAL`. 改派或新任务分别验证角色与报价归属 |
| 订单提交后丢响应, 再撤销 G1 | B1 用旧路径重试被拒, 随后停发并执行核账 | 关联原创建决定与回执, 查明订单结果及历史完整性. 与 [E7 故障对账](../e7/method.md)交叉核对 |

每条轨迹记录生效时点, 前后状态与权限, 绝对截止, 路径, 重签和重发次数, 对应决定. 关联模型推理及工具轨迹, 管理结果, 报价, 主库订单和核账回执.

## 5 判据与缺测

逐条核对表中的生效条件, 拒绝或恢复结果和实际业务副作用. 若未观测到变更块应用, 模型工具调用或核账结论, 按阶段记录原因和已获得的证据. 共享的安全条件可查 [S01-S103](../验证用例.md#2-身份-请求与父子约束).

## 6 结果表和图

按轨迹报告生效点, 旧材料与新材料的访问结果, 报价归属, 有效范围与截止, 重签及交付次数. 用代表性时序图展示改派后重新询价及响应丢失后的核账, 以运行 ID 关联 `dynamic_events.csv`, 请求, 模型轨迹和主库记录.
