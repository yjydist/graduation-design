# 实施任务

本清单交付 Fabric D0 账本切片及配套契约. 机制见 [设计](design.md), 行为验收依据为 [许可账本](specs/permissioned-ledger/spec.md), [授权登记](specs/authorization-registry/spec.md) 和 [固定高度状态](specs/fixed-height-state/spec.md).

## 1. 通道与运行基线

- [x] 1.1 在 `infra/fabric/` 增加隔离的 Compose 网络, 配置 A/B/C 各一个 Peer, 四个 SmartBFT 排序节点及 C 的视图库. 在目标 arm64 环境验证镜像可运行, 记录 Fabric 3.1.x 补丁版本, 镜像 digest, 工具链, 宿主资源及节点控制方.
- [x] 1.2 生成通道创世材料和分离的节点, 客户端及 TLS 密钥. 配置 A/B/C 和 T 的 MSP, 通道准入, BFT 区块签名策略及三域链码治理策略. 核对各 Peer 的创世块哈希与四个排序身份, 验证无通道资格的读写和排序尝试被拒绝.
- [x] 1.3 提供独立的 `mise` 启停和配置入口及 Fabric 网络说明. 按说明验证默认停机保留卷, 显式重建隔离旧实例.
- [x] 1.4 更新 [毕设要求](../../../毕设要求.md) 的联盟链技术路线及 [技术栈](../../../docs/implementation/技术栈.md) 的网络, 治理与依赖条目. 核对 R1-R5, 任务编号和三域业务边界, 将实测锁定材料与实验假设分别写清.

## 2. 部署绑定与登记链码

- [x] 2.1 构建并部署 Go 登记链码, 固定引导清单摘要及初始化客户端证书, 原子写入 RootRecord, instanceId 和 U 任务创建资格. 验证未经批准初始化, 清单单项篡改, 重复初始化和单组织变更链码定义均被拒绝.
- [x] 2.2 实现 Fabric 部署标识计算和启动核验, 保存创世块, 链码定义及各组织安装标识. 用固定向量复算 deploymentId, 测试错误通道, 根, 实例, 策略或链码定义使在线读取未就绪, 旧部署材料不能跨部署使用.
- [x] 2.3 实现 T 域/机构引导, 首份域认证, 本域身份及凭证锚登记. 用真实管理证书验证角色匹配, 当前资格, 主体归属及版本, 覆盖同 MSP 的错误证书, 跨域注册, 越界签发和非 T 引导负例.
- [x] 2.4 实现 U 任务及 RP G0/G1 登记, 用合成材料建立真实交易夹具. 验证 U 的固定资格, C 的资源方绑定, 父受托者权限及父摘要/根/任务/模式/密钥/期限/深度约束, 每项负例配同条件正例.
- [x] 2.5 实现撤销与原子替换. 验证有权调用者增加 revision 并产生 REVOKED, 无关调用者及 T 被拒绝, 终态及 ID 不可复用. 验证仅原 issuer 可替换, 合法替换同时更新新旧记录, 失败替换无写入.
- [x] 2.6 启用并锁定三域 Peer 的提案时间窗口和校时假设, 为需当前资格的操作实现时间容差检查. 对照正常提案, 回填时间和临界时刻, 记录背书后延迟到期的提交结果及下游交付所需的实际期限复核规则.
- [x] 2.7 同步 [部署与链上登记](../../../docs/implementation/部署与链上登记.md) 的治理, 角色及恢复契约, [协议编码与测试向量](../../../docs/implementation/协议编码与测试向量.md) 的部署绑定与管理证书双证明, 以及 [跨域身份](../../../docs/design/跨域身份与信任.md) 的信任边界. 提供可复算的部署标识和管理证明向量, 标明合成夹具与真实凭证验证的证据范围.
- [x] 2.8 修复首次初始化提案已保存但尚未背书时的中断恢复. 保留原操作和 txID, 仅在已确认背书拒绝, 无已签交易且可信 Peer 确认根为空时允许显式使用新操作键续跑. 补测该中断点, 在独立空卷复跑 D0 并更新核验结论.
- [x] 2.9 修复根已有效提交但部署清单未写出时的续跑. 复用经三域批准的安装包和可信 Peer 的原初始化交易, 保留旧操作. 将重复初始化负例移入验收, 并补保存旧重复提案后中断的部署续跑回归.
- [x] 2.10 签发凭证锚时校验有效区间包含于当前 T 域认证区间. 用同一 IA 和配对材料验证起点早一秒和截止晚一秒均被拒绝, 两端等于认证边界时可有效提交.

## 3. 提交确认与原交易恢复

- [x] 3.1 接入 Go Fabric Gateway, 按操作键持久化输入摘要, 原提案/txID 和已签交易. 验证同键同输入只返回原操作, 同键异输入冲突, 并发受理及进程中断不生成替代交易.
- [x] 3.2 从可信 Peer 核对提交校验码及原区块/交易位置, 区分确定性提案拒绝, VALID, 入块无效和 PENDING. 用同版本的两份已背书交易测试 MVCC 竞争, 用先排序的资格变更测试读集依赖, 并验证不足两组织背书的交易不改变登记.
- [x] 3.3 注入提交响应丢失, 结果暂不可见及重复广播. 验证恢复沿用原 txID 和已签字节, 重播的 DUPLICATE_TXID 不覆盖原结果, 缺确切原因时使用对应阶段的通用错误.
- [x] 3.4 同步 [部署与链上登记](../../../docs/implementation/部署与链上登记.md) 的提交与取证规则, [REST 接口与响应码](../../../docs/implementation/REST接口与响应码.md) 的操作字段和错误映射, [策略输入与数据约束](../../../docs/implementation/策略输入与数据约束.md) 的操作日志及交付门槛. 对照 S100/S101 确认受理前 409, 受理后 202, 查询原操作及 VALID 后交付的契约一致.
- [x] 3.5 修复 `invoke` 在 C Peer 停机时的同键重试. 补测同输入返回原操作, 异输入报告冲突, 恢复后仍确认原已签交易. 在独立空卷复跑 D0 并保存证据.

## 4. 已提交状态视图与探针

- [x] 4.1 连接 C 的可信 Peer 完整区块流, 核对通道, 区块连续性, 数据/父块哈希和交易校验元数据. 测试重复块, 缺块, 回退, 同高冲突及关键通道或链码定义变更后的拒绝和续读.
- [x] 4.2 将有效登记写集, 历史版本和检查点在一个 PostgreSQL 事务内应用. 测试同块多次写入, 无效交易被跳过, 删除标记, 事务中断和重放幂等.
- [x] 4.3 实现 `check` 的一致快照装配及 `inspect --block` 的历史复查. 在读取 G0/G1 中间应用撤销块, 验证整次读取仍取原高度. 用 h/r 核对 ACTIVE/REVOKED, 并验证依赖缺失或历史缺口时整次失败.
- [x] 4.4 实现探针链码入口及每实例周期提交. 验证专用调用者只写自己的探针键, 普通客户端不能生成被接受的探针, 探针事务和登记业务键无共享写入.
- [x] 4.5 实现单调计时, 原 txID 匹配和检查点门槛. 验证尚未应用区块, 无效, 迟到或重复的探针不能续期, 到期当刻拒绝, 进程重启须提交新探针. 默认 1 秒发送间隔和 5 秒期限均纳入配置及证据.
- [x] 4.6 同步 [请求认证与状态一致性](../../../docs/design/请求认证与状态一致性.md), [威胁模型与安全目标](../../../docs/design/威胁模型与安全目标.md) 及 [网关执行契约](../../../docs/implementation/证据交付与网关执行.md). 核对在线与历史模式, 可信 Peer 前提, 探针窗口及断流恢复在文档和 CLI 输出中语义一致.

## 5. 采购消费契约与实验判据

- [x] 5.1 同步后续网关的锁后检查点比对, 整次重验, OPA 求值, 挑战和订单幂等以及 `decision_at` 规则. 更新 [策略输入与数据约束](../../../docs/implementation/策略输入与数据约束.md) 和 [订单核账](../../../docs/implementation/订单核账.md), 核对锁后风险升高及期限已到的拒绝条件, 订单能关联所用视图, 探针原期限及 h/r 历史.
- [x] 5.2 同步 [验证用例](../../../docs/experiments/验证用例.md) 的部署, 身份, 登记, 并发与动态失效判据, 保留既有 F/S 编号. 区分 D0 合成登记夹具, M1 中 U 持 RP 根的真实询价, 以及 M2 中两种根各自的 800 元允许, 1200 元越权, C 独立拒绝, 祖先失效及并发幂等.
- [x] 5.3 重写 [实验计划](../../../docs/experiments/实验计划.md) 中 E6/E7 的观测点及失败判据. 核对撤销发送, Peer 首次观测 VALID, 视图应用 r, 各实例采用高度及最后放行和首次拒绝的字段. 采用 r 或更高视图后仍放行旧路径, 或超出原探针期限放行, 均判失败. 分开记录排序故障, Peer 或交付故障, 等锁时撤销及未知提交, 区分业务验证与 D0 状态验证.
- [x] 5.4 更新 E4/E5/E8 的三组同语义对照, 分别用中心化快照, Fabric 视图逐次装配, 同一 Fabric 视图加静态验签缓存. 核对请求交互, 验签耗时, 尾延迟, 拒绝率及背书, 排序, 探针和视图同步的开销字段. 将原 EVM gas, RPC 查头和空块指标换成可观测的 Fabric 阶段耗时, 字节及资源消耗.
- [x] 5.5 同步设计, 实现和实验三个导航的 R1-R5 映射及章节链接. 按同一采购任务核对状态, 术语和错误码在任务书, 设计, 实现契约及实验判据中的含义.
