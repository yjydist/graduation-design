# Spec Delta: reproducible-procurement-experiments

## MODIFIED Requirements

### Requirement: 正式实验固定可重建的运行输入

实验代码 SHALL 作为独立 Go 模块运行, 仅通过平台与协议模块的公开 API, `ledgerctl` CLI, HTTP 或 MCP 接口调用被测系统, 并提供统一的实验命令行入口 (`exp`) 承载基线运行, 正式实验编排与离线复算. 正式实验入口 SHALL 在构建或启动实例前分配唯一运行 ID, 保存实验编号, 计划用例或采样条件, 被测系统版本, 驱动和入口的版本或可重建源码快照, 配置及适用种子, 随运行补录实际构建标识, 二进制摘要, 实例与环境, 适用的夹具及策略摘要. 每轮复跑 SHALL 使用独立记录及适用的干净运行状态; 重构后的正式实验直接面向新架构数据格式运行, 不要求兼容重构前遗留的旧运行目录格式.

#### Scenario: 在干净环境复跑配对配置

- **WHEN** 操作者通过统一实验 CLI 以相同输入复跑一个配对实验
- **THEN** 两份清单均可定位被测系统, 驱动, 构建配置和各自实际的实例或数据库. 按计划配对的组使用相同逻辑输入, 并记录对照变量及实际环境差异
- **AND** 新轮次采用新运行 ID, 原轮样本和清单保持可查

#### Scenario: 记录真实智能体驱动与确定性驱动

- **WHEN** E1 或 E3 的正式轮次通过真实模型调用协议工具, 或其余实验采用确定性工具层驱动
- **THEN** 清单标明实际驱动方式. 真实模型轮次记录服务地址, 接口协议, 实际模型及与用例关联的推理和工具轨迹. 确定性轮次记录其实际采样参数
- **AND** 对外运行记录仅导出核对所需字段, 排除 API 密钥, 私钥, 账号盐, 完整披露和访问令牌

#### Scenario: 编译期隔离实验与平台内部实现

- **WHEN** 独立检查实验模块与平台模块的依赖图
- **THEN** 平台与链码模块零实验依赖, 实验模块仅依赖平台与协议模块的公开包且不触碰平台私有实现
