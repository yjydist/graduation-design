# 毕业设计论文写作工作区

本目录为毕业设计论文 "基于区块链的智能体跨域认证与委托授权方法研究" 的 Markdown 写作工作区.

## 目录文件

| 文件 | 用途 |
| --- | --- |
| [thesis.md](thesis.md) | 论文单文件正文草稿, 按任务书 R1-R5 组织完整章节结构 |
| [references.md](references.md) | 已核对的 13 篇核心/补充参考文献元信息表 (含正式 DOI 与官方链接) 及技术标准清单 |

## 写作与交付规范

1. **单文件专注内容**: 所有章节正文均在 [thesis.md](thesis.md) 中撰写与校对, 完成后统一复制到学校 `.docx` 模板做最终排版, 仓库内不维护 PDF 编译脚本或本地参考论文 PDF.
2. **原创与查重红线**: 论文文字复制比必须小于等于 10%; 引用他人观点, 数据或机制时须在正文显式标注对应 [references.md](references.md) 文献编号, 严禁直接照搬文献或网络段落.
3. **标点与排版约定**: Markdown 正文统一使用简体中文与 ASCII 半角标点 (逗号后加空格, 句末用 `.`, 引号用 `"`), 图表优先使用 Mermaid 或规范表格.
4. **证据口径分离**: 写作时严格区分三类材料: 外部文献依据 ([references.md](references.md)), 本项目设计与实现契约 ([docs/DESIGN.md](../docs/DESIGN.md), [docs/IMPLEMENTATION.md](../docs/IMPLEMENTATION.md)) 以及实测运行证据 ([experiments/README.md](../experiments/README.md)). 不将尚未运行的占位数据写成实测结果.
