## 第 1 章 绪论

### 1.1 研究背景与意义

- 多主体与大模型智能体 (`AI Agent`) 跨组织协同采购等场景中的身份异构, 信任边界模糊与授权动态变化问题 (对应 R1, 参考 [S4](references.md)).
- 传统中心化身份联盟与静态宽权限令牌在多级转委托, 上游撤销级联失效及可审计追责方面的不足.
- 结合联盟链分布式信任锚与链下确定性协议工具层隔离 LLM 幻觉/越权风险的工程价值.

### 1.2 国内外研究现状简述

- 跨域身份与去中心化标识研究现状 ([A1, A2, A3](references.md)).
- 轻量化跨域认证与凭证撤销研究现状 ([B1, B2, B3, S1, S5](references.md)).
- 策略驱动访问控制与受限多跳委托研究现状 ([C1, C2, S2, S3, S4](references.md)).
- 现有方案在"三域平等协作 + 统一高度一致视图 + 动态风险环境 + 真实智能体工具隔离"组合场景中的研究缺口.

### 1.3 本文主要研究内容

对照[任务书要求](../毕设要求.md) R1-R5 与五项具体任务展开:

1. **跨域身份信任链机制 (R2 / 任务 1)**: 共同身份信任根 T, 域签发资格认证, 域内身份注册, 双域关联与密钥/管理账户恢复.
2. **轻量化跨域认证协议 (R3 / 任务 2)**: 链下 SD-JWT 按需披露, 挑战持有者绑定 (`KB-JWT`), 固定高度一致视图与单调时钟探针新鲜度界定.
3. **策略驱动细粒度委托授权模型 (R4 / 任务 3)**: 双模式根授权 (`RP` / `BM`), 逐跳权限收缩, 祖先失效级联拦截, 锁后 OPA 动态复核与未知订单核账.
4. **原型系统实现与实验验证 (R5 / 任务 4, 5)**: 基于 Hyperledger Fabric 3.1.5 (SmartBFT), Go 四模块五层架构, OPA 与 MCP 的三域原型系统, 以及安全回归与 E1-E8 量化评测.

## 第 2 章 相关工作与技术基础

### 2.1 跨域身份与去中心化信任模型

- 梳理 [A1] 的 SSI 信任边界分析框架, 明确链上登记不等价于签发者真实可信.
- 对比 [A2] (账号承诺与链上绑定) 与 [A3] (层级签发与委托链), 说明本课题引入共同权威根 T 认证域资格的取舍.

### 2.2 轻量化跨域认证与凭证状态撤销

- 对比 [B1] (zkSNARK 匿名凭证), [B2] (FIDO-AC 会话绑定) 与 [S1] (区块链跨域认证) 在交互轮数, 计算开销和审计需求上的权衡.
- 对比 [B3] (累加器撤销) 与 [S5] (周期发布撤销) 的状态传播延迟与离线边界, 引出本课题基于可信 Peer 固定块高与单调时钟探针的撤销窗口模型.

### 2.3 策略驱动授权与受限多跳委托

- 结合 [C1] (Cedar 策略语言) 与 [S2] (动态跨域 ABAC), 讨论策略输入可信性与求值确定性.
- 结合 [C2] (受限再委托), [S3] (SSI/VC 委托模型) 与 [S4] (AI 智能体可认证委托), 分析智能体身份与委托权限分离及权限逐跳不扩张约束.

### 2.4 关键技术基础

- Hyperledger Fabric 3.1.5 许可通道与 SmartBFT 拜占庭容错排序.
- `did:web`, W3C VC v2.0, RFC 9901 SD-JWT (`KB-JWT`) 与 RFC 8785 JCS 规范化摘要.
- 内嵌 OPA / Rego v1 策略引擎与 PostgreSQL 行锁事务一致性.
- Model Context Protocol (MCP) 与智能体决策层/确定性工具层解耦.

## 第 3 章 总体设计与跨域身份信任机制

> 对应需求 R1, R2; 设计依据详见 [docs/DESIGN.md](../docs/DESIGN.md).

### 3.1 三域协同采购场景与系统总体架构

- 采购域 A (`U`, `A₁`, `PA`), 协作服务域 B (`B₁`/`B₂`), 供应商域 C 与外部共同身份信任根 T 的角色分工.
- 两条逻辑证据链分离: 身份证据链 (`T -> IA/IB/IC -> 主体`) 与采购委托链 (`G0 -> G1 -> G2`).
- 五层单向依赖软件架构 (L1 基础设施层 -> L2 逻辑封装层 -> L3 服务接口层 -> L4 Agent 推理层 -> L5 应用层) 与 LLM 决策层/确定性工具层隔离设计.

### 3.2 共同身份信任根与域签发资格认证

- 固定预置根 T 的 `RootRecord` 与本地根 DID 文档摘要校验, 换根须新部署的边界.
- `DomainAuthorityCredential` 结构与 `identityIssuers` 有限权限集合约束 (禁止通配符, 禁止跨域签发与转授资格).
- 域状态 (`PENDING` / `ACTIVE` / `SUSPENDED` / `REVOKED`) 与域认证原子替换语义.

### 3.3 域内身份注册, 双域关联与账户恢复

- 带盐账号承诺 (`grad-account-v1`) 与应用密钥/Fabric 管理证书双证明注册流程.
- 双域关联 (`IdentityLink`) 的对称审批提案, 有效性与不转移采购权的隔离原则.
- 身份状态机 (`ACTIVE` / `SUSPENDED` / `REVOKED`), 密钥轮换与无旧管理私钥前提下的注册机构核实恢复流程.

### 3.4 威胁模型与安全目标 (SG1-SG6)

- 攻击者能力建模 (含 LLM 幻觉, 目标漂移与提示词注入诱导的越界/重放请求) 与显式信任假设.
- 六项安全目标 SG1-SG6 及其依赖前提矩阵.

## 第 4 章 轻量化跨域认证协议与委托授权模型

> 对应需求 R3, R4; 协议字段与执行规格详见 [docs/IMPLEMENTATION.md](../docs/IMPLEMENTATION.md).

### 4.1 链下凭证按需披露与请求持有者绑定

- 完整访问证据包 (`AccessEvidencePackage`) 的七字段序列化契约与 `requestHash` / `chainHash` / `evidenceHash` 复算公式.
- 32 字节规范无填充 base64url 挑战 `nonce` 编码与 `KB-JWT` (`urn:grad:binding`) 单次请求绑定机制.
- 链上仅存摘要, 版本与状态, 链下按需披露与逐跳 mTLS 受控交付的通信开销优化.

### 4.2 固定区块高度一致视图与新鲜度界定

- C 端从自管可信 Peer 接收完整块并在同一 PostgreSQL 事务中应用 VALID 写集与检查点 (`fabric_head` / `fabric_block` / `fabric_version` / `fabric_current`).
- 只读 `REPEATABLE READ` 固定高度装配全部依赖, 消除跨对象状态撕裂.
- 进程内单调时钟专用探针 (`sentMono + deltaState`) 机制与撤销后的有界决策窗口 (`h < r` 与 `h >= r`) 形式化分析.

### 4.3 双模式根授权与逐跳收缩委托链

- 资源方预授权 (`RP`, C 签发) 与采购方代表权 (`BM`, A 域 PA 签发) 两种 G0 权源的统一验证路径与分支资格校验.
- 子授权五维收缩规则 (资源/动作/供应商有限子集, 任务/模式/受众/币种逐跳相等, 单笔上限不增, `[nbf, exp)` 嵌套包含, 剩余深度递减).
- 祖先暂停/撤销/原子替换 (`Replace`) 的 O(1) 级联失效语义.

### 4.4 锁后复核策略求值与未知订单核账

- 网关执行事务加锁顺序 (`challenges -> trusted_contexts -> business_keys -> fabric_head`), 锁后取 `clock_timestamp()` 重算 OPA 输入与有效截止.
- 基于 `client_actions` 意图锁, `sendRevision >= 2` 停发机制与 `order_outcome_outbox` 的未知订单三态核账 (`CREATED` / `NOT_CREATED` / `UNKNOWN`).
- 基于 `decision_evidence` 的固定高度历史审计重放 (`MATCHED` / `INCOMPLETE` / `MISMATCH`).
